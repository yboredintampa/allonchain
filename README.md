Open the site locally: open index.html in a browser (or: python3 -m http.server 8080 from this folder, then visit http://localhost:8080).
This folder is a single-page static site; index.html is self-contained (inline CSS, no external assets).
GitHub Pages can host this folder for free: push the repo and enable Pages on the main branch /docs or root.
Vercel can host this folder for free on the Hobby plan: import the repo or deploy the directory.
A custom domain is optional; yourname.github.io or a vercel.app URL works in an X profile today.
Contact on the page uses mailto: and public profile links only — nothing is purchased or wired to a backend.
Do not put League Lock as the main link; that product is called out separately on the page.
Edit index.html, save, and refresh — no build step required.
